Slide 03 · Gap Analysis
Why Traditional Systems Fail

Why Traditional Monitoring Is Insufficient

Analyzing the 6 systemic failure modes in legacy parking infrastructure.

01 · PASSIVE CCTV

Continuous Raw Video

Cameras stream pixels without extracting structured occupancy or vehicle status.

02 · FRAGMENTED DATA

Isolated Siloed Tech

ANPR at gates, magnetic loops in asphalt, and signage operate in disconnected databases.

03 · MANUAL MONITORING

Operator Fatigue

Security guards must stare at dozens of CRT/LCD feeds to detect violations manually.

04 · NO SPATIAL INTELLIGENCE

Detections Lack Coordinates

A bounding box on camera does not tell the system which physical parking bay it occupies.

05 · ZERO DRIVER ASSISTANCE

Blind Aisle Circling

Drivers search blindly for spaces, producing unnecessary fuel burn and campus congestion.

06 · NO UNIFIED MODEL

Missing Physical-Digital Link

No single live chain connecting: Vehicle → Camera → Space → Event → User.

Core Design Axiom: Connect Vehicle Intelligence with Spatial Intelligence. ParkTwin Principle

Slide 04 · Engineering Methodology
Perception $\rightarrow$ Event $\rightarrow$ Action

Engineering Methodology

Converting pixel observations into structured, timestamped parking events.

STEP 1

Camera Ingestion Layer

Consumes RTSP/ONVIF streams, NVR network video, or recorded ground-truth MP4 camera feeds.

STEP 2

Computer Vision Pipeline

• YOLOv8: Real-time bounding box vehicle detection & classification.
• ByteTrack: Multi-object tracking across frames with trajectory permanence.
• PaddleOCR & EasyOCR: License-plate localization and alphanumeric OCR.

STEP 3

Structured Event Generation

Detections are published as immutable JSON telemetry deltas to an asynchronous event bus.

STRUCTURED EVENT SCHEMA aiosqlite + FastSSE 
{
  "event_id": "evt_9a41b2",
  "vehicle_id": "VEH-001",
  "license_plate": "KA05ML7220",
  "camera_id": "CAM-01-ENTRY",
  "timestamp": "2026-10-03T12:00:15Z",
  "position_xy": [142.5, 88.2],
  "movement_vector": "APPROACHING_GATE",
  "confidence": 0.94
}
The event is the foundational unit of truth across the entire platform.
Vision outputs structured events $\rightarrow$ Intelligence reasons over state. CV Pipeline

Slide 06 · End-to-End Lifecycle
Vehicle Entry $\rightarrow$ Parking $\rightarrow$ Exit

The Closed-Loop Vehicle Journey

An 8-stage continuous lifecycle from entrance barrier arrival to facility departure.

01 · ENTRY

Facility Ingress

Vehicle approaches entry boom barrier.

02 · IDENTIFICATION

ANPR & Tracking

Camera extracts plate; tracking ID assigned.

03 · STATE CREATION

Telemetry Delta

Structured vehicle arrival event emitted.

04 · PARKING DECISION

Slot Allocation

Associates reserved bay or dynamic space.

05 · NAVIGATION

Indoor Wayfinding

Twin generates turn route along aisles.

06 · PARKING

Bay Occupied

Vehicle occupies slot; state becomes OCCUPIED.

07 · MONITORING

Active Session

Dwell-time tracked with wall-clock clock.

08 · EXIT

Egress & Settlement

Camera detects exit; bay liberated in Twin.

One continuous data pipeline: Camera $\rightarrow$ Event $\rightarrow$ State $\rightarrow$ Digital Twin $\rightarrow$ Navigation $\rightarrow$ Exit.
Entry $\rightarrow$ Identification $\rightarrow$ Allocation $\rightarrow$ Navigation $\rightarrow$ Parking $\rightarrow$ Monitoring $\rightarrow$ Exit. Lifecycle
