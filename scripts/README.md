# ParkTwin AI — Scripts

Utility scripts for operating the platform. Reserved for Module 1 and future modules:

- `run_demo.py` — launch a demonstration of the vehicle-recognition pipeline.
- `download_models.py` — fetch/pre-stage model weights under `models/`.
- `evaluate.py` — evaluation/benchmark harness for recognition quality.

These are intentionally left as documented placeholders so the `scripts/` package
matches the target production layout; they are added when their capability lands.
