# Support

Need help with ParkTwin AI? Here is where to look.

## Documentation

Start with the docs in the repo:

- [README.md](README.md) — project overview, install, run, API surface.
- [PROJECT_MEMORY.md](PROJECT_MEMORY.md) — architecture source of truth, module
  ownership, API inventory, duplicate registry.
- [docs/architecture/architecture.md](docs/architecture/architecture.md) —
  layout and dependency rules.
- [docs/developer-guide/](docs/developer-guide/) — module responsibilities,
  conventions, how to add modules/pages, testing.
- [docs/deployment/](docs/deployment/) — production, Docker, reverse proxy,
  HTTPS, env vars, health checks, logging, troubleshooting.
- [docs/api/](docs/api/) — endpoint reference.
- [docs/diagrams/](docs/diagrams/) — Mermaid architecture & flow diagrams.

## Getting help

- **Questions / how-to:** open a [Discussion](../../discussions) (if enabled) or
  a GitHub issue using the question template.
- **Bugs:** open an issue using the bug-report template.
- **Feature requests:** open an issue using the feature-request template.
- **Security issues:** follow [SECURITY.md](SECURITY.md) — **do not** open a
  public issue.

## Before you ask

1. Run the tests / build gates (see
   [CONTRIBUTING.md](CONTRIBUTING.md#testing-requirements)).
2. Check [Troubleshooting](docs/deployment/troubleshooting.md).
3. Search existing issues and the docs.

## Scope

This is a community/open-source project. Support is best-effort via GitHub
issues and discussions. For production deployments, follow the
[deployment guide](docs/deployment/production.md) and add authentication before
any public exposure (see [SECURITY.md](SECURITY.md)).
